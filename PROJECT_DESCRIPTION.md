# AI Incident Support Copilot

> An intelligent, AI-powered customer support ticket management system with a beautiful, modern interface.

## 🎯 What is this?

AI Incident Support Copilot is a production-ready web application that revolutionizes customer support operations by combining traditional ticket management with cutting-edge AI capabilities. Built with React, TypeScript, FastAPI, and Google's Gemini AI, it provides instant, context-aware response suggestions using RAG (Retrieval-Augmented Generation) technology.

## ✨ Key Features

- **🤖 AI-Powered Suggestions** - Get intelligent response recommendations based on ticket context and knowledge base
- **🎨 Beautiful UI** - Modern interface with light/dark modes following Google Material Design
- **⚡ Lightning Fast** - Optimized for 60fps animations and sub-second load times
- **♿ Fully Accessible** - WCAG 2.1 AA compliant with keyboard navigation and screen reader support
- **📊 Real-time Analytics** - Interactive charts and metrics for ticket trends and performance
- **🔍 Smart Search** - Instant search with debouncing and multi-criteria filtering
- **📱 Responsive Design** - Works perfectly on desktop, tablet, and mobile devices

## 🚀 Quick Start

```bash
# Clone the repository
git clone <repository-url>
cd ai-incident-support-copilot

# Run the application (one command!)
./start.sh          # Mac/Linux
start.bat           # Windows
npm run dev         # Any platform
```

Open http://localhost:5173 and login with:
- Email: `admin@example.com`
- Password: `admin123`

## 🛠️ Tech Stack

**Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Recharts  
**Backend:** FastAPI, Python 3.11+, SQLAlchemy, SQLite  
**AI/ML:** Google Gemini Pro, LangChain, FAISS, Sentence Transformers  
**Testing:** Vitest, Testing Library, Fast-check (Property-based testing)
